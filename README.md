# Escape Canyon

프롬프트와 채택 에셋이다. 보드에 있는 글과 그림을 그대로 옮겼다.

- [prompt-setting.txt](prompt-setting.txt) — Prompt Setting 본문
- [default-prompt.txt](default-prompt.txt) — Default Prompt 본문
- [assets](assets) — 채택 후보 에셋. 파일 픽셀 크기가 보드에 올린 그림과 같다.

```
assets/player
assets/bighorn
assets/condor
assets/squirrel
assets/gray_wolf
assets/item
assets/platform
assets/wind
assets/map
```

맵은 `assets/map/01.png`부터 `10.png`다. 10이 맨 위 화면이다.

아이템 픽셀 크기는 신발 50×52, 방패 39×50, 우산 50×54다.
